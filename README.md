# Onnenpyörä
Finnish Wheel of Fortune game based on TV series in 90s what runs on Windows 95/98/NT. It is written in 1998 with Visual Basic 5. I found an old backup of the source code and decided now to share the code. At the time of writing this I was 19 years old and didn't have much experience in (Windows) Programming.

You can find the zip package of the game here:
https://tiedostot.apajalista.net/SGH/Windows/Onnenpyörä/OPYOR14.ZIP
